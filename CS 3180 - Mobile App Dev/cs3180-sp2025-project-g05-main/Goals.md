# Goals.md

These are the goals we have set out for our project. They are seperated into realistic ones, that we hope to get done, and stretch goals, that will be completed if we have enough time and knowledge.

## All pages
**Realistic Goals**
* Bottom Bar for multiple pages

**Stretch Goals**
* Different UI based on Start/stop, ex. a Simplified version for when you're riding and wearing gloves. Or more complex version.


## Home page
**Realistic Goals**
* Compass for Wind Direction
* Current Weather
* Start / Stop buttons to record trips
* Show Battery percentage

**Stretch Goals**
* Caution notification/popup for extreme weather or battery issues.

## Battery Page
**Realistic Goals**
- Current Percentage
- General Health
- Cell Temperature
- Distance or Time remaining until Depleted

**Stretch Goals**
- Add multiple bikes / batteries.

## Trips Page
**Realistic Goals**
- Add locations for trips, (auto calculate distance)

## Calc Page
**Realistic Goals**
- Enter information about how you ride, width of tires, amount of power rider is contributing
